# Auvra

The official website of [Auvra](https://www.goauvra.com), a cultural technology platform building the permanent home for human culture.

## Overview

The site is built with Astro and React, styled with Tailwind CSS, and deployed on Vercel. Pages are pre-rendered to static HTML for speed, accessibility and search visibility.

## Development

Access is limited to the Auvra team.

```bash
npm install
npm run dev      # start a local server
npm run build    # build for production
```
